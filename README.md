# Martha's Healing Touch — Website

Premium medical spa website for Pembroke Pines, FL.

## Stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion + GSAP (scroll animations)
- Booksy · WhatsApp · Google Maps integrations

## Quick start

```powershell
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Documentation

Full design spec, Higgsfield prompts, copy, and asset list:

→ [`docs/DESIGN_SPEC.md`](docs/DESIGN_SPEC.md)

## Before launch

1. Add Higgsfield videos to `public/videos/`
2. Replace placeholder images in `public/images/`
3. Update Booksy URL in `src/lib/site-config.ts`
4. Update Google Maps embed URL
